# Git Collaboration Practice

## Objective

Practise Git branching, commits, pull requests, code reviews, and GitHub Issues.

## Workflow

1. Create a feature branch.
2. Make and commit a change.
3. Push the branch to GitHub.
4. Open a pull request for review.
5. Review the changes and merge the pull request.

## Learning Outcome

Understand how Git branches and pull requests support collaborative software development.
